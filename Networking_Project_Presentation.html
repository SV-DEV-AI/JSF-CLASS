Exp 6: Smart Office Scenario

Aim: Design and secure a multi-department corporate network.

  • Departments: HR, Accounts, Developers, Testing, Server Room.
  • Access Policy: Only Developers can access the Server Room.
  • Privacy: HR data is isolated, restricted to outbound internet only.
  • Global Connectivity: Outbound internet access via NAT Overload.

Exp 6: Network Architecture

  • VLANs (Virtual LANs): Logical broadcast containment.
  • 802.1Q Trunking & ROAS: Efficient inter-VLAN routing without multiple physical interfaces.
  • NAT Overload (PAT): Maps internal private subnets to a public IP.
  • Extended ACLs: Strict internal firewall filtering based on Source/Dest IP & Protocol.

Exp 6: Testing & Results

  • Internet Connectivity: Successful pings to Google Server (8.8.8.8).
  • Security Validation: Unauthorized pings (HR/Accounts → Server) successfully blocked by router firewall ("Destination host unreachable").
  • Authorized Access: Developer PC successfully connected to Server Room.
  • Result: Zero-trust policies completely fulfilled.

Exp 7: Bank ATM Network

Aim: Simulate a highly available, multi-city ATM WAN.

  • Locations: Connect critical ATM servers in Patna, Delhi, and Mumbai.
  • Requirement: Extreme fault tolerance and high availability.
  • Resilience: Automatic rerouting during catastrophic physical link failures (e.g., severed underground fiber).

Exp 7: High Availability Design

  • Topology: Redundant 3-city triangular WAN core.
  • Protocol: OSPF (Open Shortest Path First) Link-State Routing.
  • Mechanism: Dijkstra's SPF Algorithm dynamically calculates absolute shortest paths.
  • Backbone Area 0: Facilitates rapid sharing of Link State Advertisements (LSAs).

Exp 7: Failover Simulation

  • Convergence Verified: OSPF neighbors successfully established 'FULL' adjacency states.
  • Failure Simulated: Direct Delhi-Mumbai WAN link intentionally severed.
  • Automatic Failover: tracert utility confirmed immediate, dynamic rerouting through the Patna branch.
  • Result: Zero downtime ATM transaction connectivity maintained.

Conclusion & Learning Outcomes

  • Demonstrated mastery of Layer 2 VLANs and Layer 3 Routing.
  • Proven application of NAT and Extended ACLs for strict cybersecurity.
  • Advanced understanding of redundant Enterprise WAN design.
  • Real-time implementation of OSPF fault-tolerance in mission-critical systems.
